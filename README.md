# API Gateway Service
This repository is part of the **Inkwell Book Store**, built as a distributed system project. For more information about the system check the [main page](https://github.com/inkwell-store).

## About
This repository contains an API Gateway built with spring cloud gateway mvc. It serves as the entrypoint for all requests made to any services sitting in the backend.
